Each one goes somewhere on the grid. Up the side is what the learner is actually doing. Across the bottom is what it costs them.

What decides a placement is what the person did with the output, not which tool they used. Placement is a commitment, so it locks once all six are down and the argument only appears afterwards.

Dragging works, and so does the keyboard: Tab to a card, Enter to pick it up, arrow keys to move, Enter to place, Esc to cancel.
