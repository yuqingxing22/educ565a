Course description
AP Computer Science A is an introductory college-level course in computer programming using the Java language. Students learn to design, write, and test programs using objects, selection, iteration, classes, arrays, ArrayList, 2D arrays, searching, sorting, and recursion. The course follows the College Board's four-unit AP Computer Science A course description (Unit 1: Using Objects and Methods; Unit 2: Selection and Iteration; Unit 3: Class Creation; Unit 4: Data Collections) and prepares students for the AP exam in May 2027.

Instructor: Mr. Andre Whitcombe, Virtual Program Teacher (AP Computer Science) · awhitcombe@marlowridge.fictional.edu
Office hours: Optional lunchtime Zoom help session, Thursdays 12:10 to 12:40 pm Eastern. The link is in the Help page. Email any time.
Response time: Within 2 school days. Code check questions sent after 3 pm may wait until the next school day.
Technical support (logins, course site, IDE access): District Virtual Program Help Desk · vp-helpdesk@marlowridge.fictional.edu

Learning outcomes
- Write, test, and debug Java programs that use variables, conditionals, loops, and methods.
- Design and implement classes with private data, constructors, and methods.
- Use arrays, ArrayList, and 2D arrays to store and process collections of data.
- Trace and analyze code, including searching, sorting, and recursive algorithms.
- Discuss the ethical and social impacts of computing and data use.
- Prepare for the AP Computer Science A exam.

How a week works
There is no fixed weekly schedule. A typical module takes about two weeks: read the textbook topics, watch the videos if you need them, try the code checks (unlimited attempts), then take the module quiz. Mr. Whitcombe checks the forum and email on school days, and the optional help Zoom runs Thursdays at lunch. Pair project matching happens on the 1st and 15th of each month.

Grading
- Code checks, Modules 1-10 (20): 40%
- Module quizzes, Modules 1-10 (10): 25%
- Pair project (Module 3): 10%
- Module 11 review (2 free-response style code checks and the practice quiz): 25%
A 90-100, B 80-89, C 70-79, D 60-69, F below 60. Course grade is reported to your home school at the end of each semester.

Policies
Pacing and deadlines: There are no weekly deadlines. The suggested pace is about one module every 2 weeks, with all modules finished by the end of April. Your home school's semester grade deadlines still apply, so check with your counselor. If you are more than 3 modules behind the suggested pace, Mr. Whitcombe may email you and your counselor.
Code checks and quizzes: Code checks can be retried as many times as you like. Quizzes allow 2 attempts and keep your highest score. The autograder checks output and behavior; it cannot give hints about why a test failed.
Help sessions: An optional Zoom help session runs Thursdays 12:10 to 12:40 pm Eastern. Attendance is not graded and sessions are not recorded.
Pair project: Module 3 includes a pair programming project with a partner from another school. If you cannot find a partner or your partner stops responding, email Mr. Whitcombe and you may finish the project alone.
Academic honesty: Submit your own work. Copying code from classmates or from the internet and submitting it as your own is not allowed. For the pair project, both partners should understand and be able to explain all of the code.
Technology and access: You need a computer with a modern web browser and an internet connection. Some school networks block the coding environment or video sites. If a resource is blocked at school, try from home or contact the help desk. The course is built for computers; phones can work for readings and quizzes but not for code checks.
Use of AI tools: AI tools such as chatbots may be used to help you understand a concept or to explain an error message. Do not paste a whole code check or the pair project prompt into an AI tool and submit what it writes. Code you submit must be code you understand and can explain. Some AI sites are blocked on district networks; you are not expected to use a VPN or other workaround to reach them. If you use an AI tool to help with a code check, add a one-line comment at the top of your code saying which tool you used. Mr. Whitcombe may ask you to explain your code if it looks different from your earlier work. AI use is not allowed on module quizzes.

[Assignment] Pair Project: Club Event Ticket Checker · Due Self-paced. Pairs are matched on the 1st and 15th of each month; finish within 2 weeks of being matched. · 50 points
You will be matched with a partner from a different school. Together you will write a program that a school club could use at the door of an event.

Partner A writes a static method isEligible(int age, boolean hasPermissionSlip, boolean isMember) that returns true if the student may attend: members always may; non-members need to be 14 or older or have a permission slip. Partner B writes a static method ticketPrice(int age, boolean isMember) that uses if / else if / else: members pay $2, students under 14 pay $3, everyone else pays $5. Together, write a main method that tests both methods with at least 6 cases and prints the results. Swap roles for the second half: each partner rewrites the other's method using a different but equivalent condition (De Morgan's laws are allowed).

Stay in touch using the district student email or the Pair Project message board. Choose a shared editor that works on both of your school networks. When you are done, each partner submits the same final code file and a short individual reflection (4 to 6 sentences): what you built, what your partner did well, and one thing you would do differently.

If your partner does not respond within 5 school days, email Mr. Whitcombe and you will be rematched or allowed to finish solo.
Rubric:
- isEligible returns the correct result for every rule: 12 points
- ticketPrice uses if / else if / else correctly: 12 points
- main tests at least 6 cases, including edge ages (13, 14): 8 points
- Code is readable (comments, clear names) and both partners' names are in the header: 8 points
- Individual reflection: 10 points
